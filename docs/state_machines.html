运行链路

主状态推进比赛流程；红点坐标长期流和 A4 锁存结果由视觉侧上报。

BOOT

初始化 app 状态，确认视觉在线，建立安全输出。

CALIB_SCREEN

电机失能，SPOT640 持续上报红点；K2 保存 P0~P4。

IDLE

等待 K2 启动当前模式，K3 切换模式，K1 长按复位。

RUN / RESET

RESET_RUN、SQUARE_RUN 和 A4_RUN 依赖 SPOT 新鲜坐标推进或观测。

A4 DETECT / LOCK

A4GRAY 检测 A4，LOCK_A4 后一次性锁存角点给 TI。

PAUSED / DONE / ERROR

TI 先制动，再按需发送 STOP，保留完成或失败原因。

主状态

app_red_task 管理模式、启动、暂停、完成和错误出口。

状态职责进入条件退出条件标记
BOOT初始化 app 层状态、确认视觉在线、建立安全输出。上电或软件复位。初始化完成进入 CALIB_SCREEN；关键依赖失败进入 ERROR。preview
CALIB_SCREEN电机失能，使用 SPOT640 红点坐标保存 P0~P4。BOOT 完成，或用户重新进入屏幕标定。按原点、左上、右上、右下、左下顺序全部保存后进入 IDLE；保存失败进入 ERROR。preview
IDLE等待模式选择和启动命令，保持激光输出安全。CALIB_SCREEN 完成、任务完成、用户停止、错误复位。K2 启动当前模式；K3 切换模式；K1 长按进入 RESET_RUN。preview
RESET_RUN从任意位置回到原点 P0，复位运动由 TI 和运动控制模块负责。IDLE 或运行态收到 K1 长按。到达原点进入 DONE；超时、红点失效或限位进入 ERROR；K1 短按进入 PAUSED。preview
SQUARE_RUN沿屏幕 0.5m x 0.5m 正方形边线顺时针一周，使用 P1~P4 和红点坐标。屏幕标定有效，选择屏幕边线模式并启动。一周完成进入 DONE；30 秒超时、脱轨、红点过期或输出异常进入 ERROR；K1 短按进入 PAUSED。preview
A4_DETECT请求 MaixCAM-Pro 进入 A4GRAY，等待 A4 黑色电工胶带稳定。选择 A4 或旋转 A4 模式并启动。视觉结果可锁存进入 A4_READY；检测超时或通信失败进入 ERROR；K1 短按进入 PAUSED。preview
A4_READY发送 LOCK_A4，锁存本轮 A4 角点并转换为运动控制目标点。A4_DETECT 获得稳定 A4 结果。收到 A4_LOCKED 并路径生成成功后进入 A4_RUN；角点无效、ACK 失败或映射失败进入 ERROR。preview
A4_RUN沿已锁存的 A4 黑胶带中心线路径顺时针一周，运行期切回 SPOT640 上报红点。A4_READY 路径生成完成。一周完成进入 DONE；30 秒超时、连续脱离、红点过期或运动异常进入 ERROR；K1 短按进入 PAUSED。preview
PAUSED立即制动并保留可恢复上下文。运行态收到 K1 短按。K2 恢复前一运行态；K1 长按转入 RESET_RUN；二次短按放弃并进入 IDLE。preview
DONE停止运动输出，记录正常完成原因。复位、屏幕边线或 A4 路径正常完成。状态上报完成后进入 IDLE，或等待用户确认后进入 IDLE。preview
ERROR安全输出，记录错误原因，等待用户清错或复位。初始化、标定、检测、路径、运动、通信或超时失败。清错后进入 IDLE；K1 长按可尝试 RESET_RUN；无法清错则保持。preview

路径子状态

路径进度按稳定完成边界推进。

状态职责退出条件标记
PATH_IDLE无路径任务，输出安全。主状态机装载路径后进入 PATH_LOAD。preview
PATH_LOAD校验点数、目标坐标、速度参数、限位。有效进入 PATH_GOTO_START；无效进入 PATH_FAULT。preview
PATH_GOTO_START先移动到路径起点，避免从任意位置直接扫边。到达起点进入 PATH_TRACE_SEGMENT；超时进入 PATH_FAULT。preview
PATH_TRACE_SEGMENT沿当前边线段执行插补或闭环跟踪。当前段完成进入 PATH_NEXT_SEGMENT；偏差或超时进入 PATH_FAULT。preview
PATH_NEXT_SEGMENT提交稳定完成边界，推进段号。还有线段则回 PATH_TRACE_SEGMENT；一周完成进入 PATH_DONE。preview
PATH_DONE路径正常完成，等待主状态机收尾。主状态机读取完成后回 PATH_IDLE。preview
PATH_FAULT停止运动输出，保留失败原因。主状态机进入 ERROR 后清理。preview

视觉状态

MaixCAM-Pro 只输出红点坐标流、A4 锁存结果和视觉错误原因。

状态职责进入/退出标记
VISION_IDLE等待 TI 请求，不把旧结果作为当前有效结果。收到 MODE,SPOT640 进入 VISION_SPOT640；收到 MODE,A4GRAY 进入 VISION_A4GRAY。implemented
VISION_SPOT640使用 640x480 RGB888 检测红色激光点，长期发送 SPOT。收到 MODE,A4GRAY 切换 A4 检测；收到 STOP 回 VISION_IDLE；检测异常进入 VISION_ERROR。implemented
VISION_A4GRAY固定采集 640x480，A4 测试版直接在 640x480 检测 A4 黑色电工胶带闭合框，通过外框/内孔轮廓和边线精修恢复中心线四角点并过滤不稳定候选。收到 LOCK_A4 且结果稳定进入 VISION_A4_LOCKED；未稳定时返回 ERR_A4_NOT_READY。implemented
VISION_A4_LOCKED锁存 A4 黑胶带中心线四角点、角度、置信度和帧号。发送 A4_LOCKED，直到收到 ACK,A4_LOCKED、收到新模式命令或重发次数用尽。implemented
VISION_ERROR记录红点无效、无 A4、低置信、通信或处理异常。收到新 MODE 或 STOP 后清理并切换状态。preview

TI 是命令方和状态机 owner；MaixCAM-Pro 是视觉检测 owner。

按键

三键输入统一进入主状态机；K1 按短按和长按区分。

IDLE

  • K1 短按保持停止或清错。
  • K1 长按进入 RESET_RUN。
  • K2 启动当前模式。
  • K3 切换模式。

CALIB_SCREEN

  • K1 短按放弃本轮标定。
  • K2 保存当前点。
  • K3 切换当前选择项。

运行态

  • K1 短按立即暂停并制动。
  • K1 长按转入复位。
  • K2 无动作或现场确认。
  • K3 无动作。

PAUSED

  • K1 短按放弃任务。
  • K1 长按转入复位。
  • K2 恢复运行。
  • K3 无动作。
