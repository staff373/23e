顶层

顶层只负责统一解释比赛命令、比赛流程、安全边界和子状态机启停。

Owner

app_green_system / GreenSystem，位于 MSPM0G3507 控制侧应用层。

职责

统一处理来自按键或蓝牙的 START1、START2、PAUSE、STOP、故障、安全输出、可重入新一轮启动、第一问/第二问任务选择、Q2 偏移目标和红点预测、红点丢失后持续追最后红点偏移目标、首次达标声光提示和程序层参数。

不负责

不做视觉识别细节、不直接拥有 PWM/云台外设初始化、不在中断或 UART 回调里做比赛决策。

顶层状态

LOCKED 和 LOST 不作为顶层状态，归入运行期追踪质量。

状态职责进入条件退出条件动作边界状态
IDLE待机，云台安全输出。上电完成、STOP 或故障复位。START1 或 START2。不输出普通追踪动作；蓝牙程序层调参和遥测命令仍可用。implemented
PREPARE清失败累计，延迟一个 tick 后向视觉侧发送 MODE,TRACK640。START1 或 START2 被接受。发送成功进 RUN_ACTIVE；发送失败进 FAULT。只做启动握手，不进入追踪输出闭环。implemented
RUN_ACTIVE根据 task=Q1/Q2 执行第一问固定点一次性追踪或第二问预测偏移目标连续追踪。PREPARE 成功。Q1 追到固定点、PAUSE、STOP、第一问连续失锁评分失败、视觉启动异常或非法状态。Q1 只追启动后锁定的固定点；Q2 维护 Q2_FIRST_ACQUIRE、Q2_FOLLOW、Q2_RED_LOST_GRACE、Q2_REACQUIRE_HOLD，用红点预测偏移目标控制绿点。implemented
PAUSED立即制动，保留光斑位置用于测距。蓝牙 PAUSE 触发。再次蓝牙 PAUSE 继续运行，或停止。暂停优先级高于普通追踪输出。implemented
FAULT安全停机，记录故障原因，禁止继续普通追踪。视觉启动命令发送失败、非法状态或非法命令。人工 RESET 或 STOP 回 IDLE。输出安全值，保留最后失败原因。implemented

运行期

RUN_ACTIVE 内部先按 task 分为第一问固定点一次性追踪和第二问预测偏移目标连续追踪；第二问再细分运行阶段。

运行期阶段职责进入条件退出条件输出
Q2_FIRST_ACQUIRE首次追踪阶段，使用 Q2_FIRST profile；有效红点生成预测偏移目标，转角/换向时可触发后续跟随增强。RUN_ACTIVE 初始阶段。首次 target_ok && q2_sep_ok 后进入 Q2_FOLLOW；超出首次窗口进入失锁质量状态但不自动停机。implemented
Q2_FOLLOW连续追踪阶段，使用 Q2_FOLLOW profile；每个控制周期追踪预测红点下方固定偏移目标，死区内同向小误差可通过泄漏累计补 1 步，转角增强期间降低有效死区和细步阈值。首次满足偏移目标误差和红绿最小分离保护后。红点消失进入 Q2_RED_LOST_GRACE；stale、绿点丢失或无最后红点进入 Q2_REACQUIRE_HOLD。implemented
Q2_RED_LOST_GRACE红点消失但绿点仍有效时，持续使用最后一次红点下方固定偏移目标；首次达标前仍使用 Q2_FIRST profile，首次达标后使用 Q2_FOLLOW profile。red_valid=0、green_valid=1、last_red=1。红点恢复后按是否已经首次达标回到 Q2_FOLLOW 或 Q2_FIRST_ACQUIRE；绿点丢失或 stale 后进入 Q2_REACQUIRE_HOLD。implemented
Q2_REACQUIRE_HOLD视觉 stale、绿点丢失或没有可用最后红点时安全停止当前动作，等待恢复；不因普通失锁进入最终停机。无可用追踪目标。红绿恢复后按是否已经首次达标回到 Q2_FOLLOW 或 Q2_FIRST_ACQUIRE。implemented
TRACK_LOCKED质量状态：K1 为固定点已达标，K2 为偏移目标误差达标且红绿距离满足最小分离；声光提示由独立 <=8pt 距离判断触发。target_ok=1 且 q2_sep_ok=1。K1 立即停止并回 IDLE；K2 离开达标条件或视觉不可用后进入失锁或重捕获质量状态。implemented
TRACK_UNLOCKED质量状态：当前未达标，且没有处在最后红点保护追踪状态。target_ok=0 或 q2_sep_ok=0。重新达标回 TRACK_LOCKED；Q2 仅累计 fail 供观察，不自动进入最终停机。implemented
REACQUIRE质量状态：红点消失但绿点仍有效，持续朝最后红点偏移目标运动。Q2_RED_LOST_GRACE。红点恢复后回到预测偏移目标跟随；绿点丢失或 stale 后进入失锁。implemented
SCORE_FAILED第一问评分边界使用；第二问连续追踪不再因普通失锁进入此状态。K1 超过 first_ms 仍未追到固定点。顶层进入 FAULT，等待人工停止/复位。implemented

验证

大框架验证先确认状态可观测，硬件闭环后再验证精度和时间指标。

字段

最小验证

先用按键和蓝牙分别触发 K1/START1、K2/START2、K3/STOP，确认两种来源进入同一顶层跳转；再确认重复 START1/START2 会清目标、视觉通信残留和上一轮 TRACK 缓存并重新开一轮，PGET/PSET/PDEF 可读写参数，TMON/TMOFF 输出周期遥测；START1 后第一帧有效红点坐标应锁定为固定 target_xy，红点移动后 target_xy 不再变化，K1 状态行应显示 q2=NA，运动输出使用真实 err=target-green，追到固定点后回 IDLE；START2 后应能观察 last_red、pred、pred_d、rv，预测关闭或首帧时 target_xy 约等于红点下方固定偏移，首次 target_ok && q2_sep_ok 切到 q2=FOLLOW，转角时 motion 内 boost 短时大于 0，死区泄漏可在 leak 字段观察，红点遮挡时进入 q2=RED_LOST_GRACE 并继续追最后红点偏移目标，红点恢复后回到预测偏移目标跟随。
