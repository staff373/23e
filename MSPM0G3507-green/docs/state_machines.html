顶层

顶层只负责比赛流程、安全边界和子状态机启停。

Owner

app_green_system / GreenSystem，位于 MSPM0G3507 控制侧应用层。

职责

统一处理 START、STOP、暂停、故障、安全输出、2 秒首次锁定窗口和 3 秒连续失败边界。

不负责

不做视觉识别细节、不直接拥有 PWM/云台外设初始化、不在中断或 UART 回调里做比赛决策。

顶层状态

LOCKED 和 LOST 不作为顶层状态，归入运行期追踪质量。

状态职责进入条件退出条件动作边界状态
IDLE待机，云台安全输出，声光关闭。上电完成、STOP 或故障复位。START 且依赖可用。不输出普通追踪动作。preview
PREPARE清计时、清失败、确认视觉/云台/按键链路。START 被接受。准备成功进 RUN_ACTIVE；依赖异常进 FAULT。只允许初始化子状态，不进入追踪输出闭环。preview
RUN_ACTIVE追踪运行期，管理首次锁定窗口和连续失败边界。PREPARE 成功。PAUSE、STOP、严重故障或连续失败超限。允许追踪闭环输出，仍受暂停和安全条件抢占。preview
PAUSED立即制动，保留光斑位置用于测距。暂停键触发。继续运行或停止。暂停优先级高于普通追踪输出。preview
FAULT安全停机，记录故障原因，禁止继续普通追踪。视觉长期无效、通信过期、云台异常、连续失败超限。人工 RESET 或 STOP 回 IDLE。输出安全值，保留最后失败原因。preview

运行期

RUN_ACTIVE 内部先按粗粒度追踪质量划分，后续再细化。

运行期阶段职责进入条件退出条件输出
ACQUIRE_FIRST_LOCK启动后的 2 秒窗口内争取首次进入 <=3cm。RUN_ACTIVE 初始阶段。误差达标进 TRACK_LOCKED；2 秒仍未达标进入未锁定处理。追踪输出开启，声光不报锁定。
TRACK_LOCKED红绿中心距离保持 <=3cm。视觉有效且距离达标。距离超限或视觉失效。继续闭环追踪，连续声光提示。
TRACK_UNLOCKED距离 >3cm，但尚未连续失败 3 秒。距离超限。重新达标回 TRACK_LOCKED；连续失败超限进 SCORE_FAILED。继续追踪，累计 fail_ms。
REACQUIRE视觉短暂丢失或通信过期后恢复追踪。视觉无效或帧过期。视觉恢复后按距离进入锁定或失锁；长期无效进入故障。输出限幅或保持安全追踪策略。
SCORE_FAILED连续失败超过题面 3 秒边界。fail_ms 超限。顶层进入 FAULT 或等待人工停止。安全输出，保留失败证据。
