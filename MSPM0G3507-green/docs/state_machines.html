绿色系统状态机预览

绿色激光系统当前状态机预览；依据为题面 PDF 和 PROJECT.md。仓库暂无固件源码，因此本页状态均为 preview，硬件未确认项标为 unknown。

范围依据 运行链路 主状态 转换覆盖 输入与判定 STATUS 接口 演练

范围依据

只覆盖绿色光斑自动追踪子系统，不覆盖红色路径控制实现。

比赛任务绿色光斑独立追踪红色光斑，发射端可放在线段任意位置。
成功边界启动后 2s 内两光斑中心距离 <=3cm，并发出连续声光提示。
失败边界启动 2s 后距离 >3cm 记一次失败；连续失败 3s 以上为 0 分。
暂停边界红色、绿色系统同时按下暂停键时，两光斑立即制动，便于测量中心距离。
独立性绿色系统不得通过 UART、共享变量、共享总线、无线链路或同步线接收红色系统信息。
状态标记preview 表示实现前契约；unknown 表示硬件或源码事实未确认；critical 表示比赛扣分或 0 分边界。

运行链路

app_green_tracker 是唯一 owner；视觉、云台、声光和按键只提供输入/输出接口。

BOOT

初始化 app 状态，所有输出进入安全态，清除历史锁定和失败计时。

SELF_CHECK

确认按键、云台制动、激光开关、声光输出和本地视觉/传感帧可用。

CALIBRATE

获得屏幕尺度或像素到厘米转换；未确认硬件时该状态保持 unknown。

IDLE

等待一键启动；不接收红色系统信息，只保留本地观测和手动按键事件。

ACQUIRE

在同一个 2 秒启动窗口内找到红色光斑和绿色光斑。

SEEK / LOCK

先快速靠近，再细跟踪；误差稳定在 <=3cm 后进入锁定并连续声光提示。

TRACK / RECOVER

锁定后持续跟随；偏差或光斑丢失进入恢复，连续失败 3s 转故障。

PAUSED / ERROR

暂停优先制动并保留测距位置；错误态安全输出并锁存原因。

主状态

状态推进由 GreenTracker_Poll() 完成，禁止在 ISR/HAL callback 里改业务状态。

状态职责进入条件退出条件标记
BOOT清状态、停云台、关闭或置安全声光，建立计时基准。上电或软件复位。初始化完成进入 SELF_CHECK；关键初始化失败进入 ERROR。preview
SELF_CHECK检查按键、云台、激光、声光、本地传感帧和参数范围。BOOT 完成或用户清错后重检。依赖有效且标定有效进入 IDLE；需要标定进入 CALIBRATE；失败进入 ERROR。preview
CALIBRATE建立屏幕 ROI、像素到厘米比例、绿点可控方向和云台限位。无有效标定或绿色发射端位置改变。标定完成进入 IDLE；标定超时、尺度无效或绿点不可见进入 ERROR。unknown
IDLE等待绿色系统一键启动，保持云台停止并低频上报状态。自检/标定完成、停止、清错或暂停放弃。启动键进入 ACQUIRE_RED；复位键回 SELF_CHECK；错误事件进入 ERROR。preview
ACQUIRE_RED在本地传感画面中寻找红色目标光斑。GreenTracker_Start() 接受启动，启动 2 秒计时开始。红点有效进入 ACQUIRE_GREEN；2 秒内仍无红点进入 ERROR；暂停进入 PAUSED。preview
ACQUIRE_GREEN确认自身绿色光斑可见，必要时执行小幅探测扫描。红点有效。绿点有效进入 COARSE_SEEK；绿点不可见、限位或启动超时进入 ERROR；暂停进入 PAUSED。preview
COARSE_SEEK用快速限幅控制把绿点推向红点，优先满足 2 秒内锁定。红点和绿点均有效。距离接近阈值进入 FINE_LOCK；启动 2 秒超时且未达 <=3cm 进入 ERROR；暂停进入 PAUSED。preview
FINE_LOCK低速闭环，抑制抖动并确认 <=3cm 稳定成立。COARSE_SEEK 已接近红点。稳定满足 <=3cm 进入 TRACK_LOCKED；启动 2 秒超时进入 ERROR；丢点回对应 acquire；暂停进入 PAUSED。preview
TRACK_LOCKED持续追踪红点，连续声光提示，失败计时清零。2 秒窗口内完成锁定，或恢复成功。距离 >3cm、红点/绿点过期或限位进入 TRACK_RECOVER；暂停进入 PAUSED；停止进入 IDLE。preview
TRACK_RECOVER保持追踪输出并累计连续失败时间，声光转为失锁状态。启动 2 秒后出现 >3cm、红点过期、绿点过期或限位保护。恢复 <=3cm 进入 TRACK_LOCKED；连续失败 >=3s 进入 ERROR；暂停进入 PAUSED。critical
PAUSED立即制动并保持当前光斑位置，保留前一状态、误差和失败计时。任意运行态收到暂停键。恢复键回前一运行态；停止键进入 IDLE；复位键进入 SELF_CHECK。preview
ERROR安全输出、停止云台、锁存错误原因，声光提示错误类型。自检、标定、启动锁定、连续失败、限位、传感或输出异常。清错进入 SELF_CHECK；停止进入 IDLE。preview

输入与判定

所有判定进入 GreenTracker_Poll()，输入层只更新最近样本和事件位。

输入来源有效条件失效出口标记
red_spot绿色系统本地视觉/传感。坐标在屏幕 ROI 内，置信度达标，样本年龄 <=150ms。ACQUIRE_RED 超时或 TRACK_RECOVER。unknown
green_spot绿色系统本地视觉/传感。自身绿点可见，未饱和，样本年龄 <=150ms。ACQUIRE_GREEN 超时或 TRACK_RECOVER。unknown
dist_cm10红绿光斑中心距离，单位 0.1cm。由有效标定把像素误差转换为厘米误差。无尺度时不得宣称 <=3cm 锁定。unknown
gimbal_ok二维云台 driver 或运动控制层。未触发限位、过流、输出饱和或驱动错误。ERROR，错误码 GIMBAL_LIMIT 或 DRIVE_FAIL。preview
pause_event绿色系统暂停键。去抖后短按或外部暂停输入。任意运行态立即进入 PAUSED。preview
elapsed_msHAL_GetTick() 或等价系统 tick。使用无符号差值计算，禁止阻塞等待。启动 2000ms 和连续失败 3000ms。preview

STATUS

串口或调试口的最小观测字段，能定位是否卡在视觉、云台、锁定或失败计时。

状态

state、prev、err、elapsed_ms

光斑

red_valid、green_valid、dist_cm10、frame_age

追踪

lock_ms、fail_ms、start_deadline_ms、recover_ms

输出

pan_pwm、tilt_pwm、brake、buzzer、led

示例OK GREEN state=TRACK_LOCKED red=1 green=1 dist_cm10=24 lock_ms=860 fail_ms=0 elapsed=1460 buzzer=ON led=ON err=0
失锁示例OK GREEN state=TRACK_RECOVER red=1 green=1 dist_cm10=42 lock_ms=3310 fail_ms=620 elapsed=5140 buzzer=LOSS led=BLINK err=DIST_GT_3CM
故障示例ERR GREEN state=ERROR red=1 green=1 dist_cm10=57 lock_ms=3310 fail_ms=3000 elapsed=7520 buzzer=FAULT led=FAULT err=TRACK_FAIL_3S

接口

公开 API 只暴露启动、暂停、停止、状态和参数；命令层不直接改私有状态。

API职责标记
void GreenTracker_Init(void)初始化状态机变量，不重复初始化外设。preview
void GreenTracker_Poll(void)唯一状态推进入口，处理计时、转移、输出和错误锁存。preview
uint8_t GreenTracker_Start(void)从 IDLE 接受启动，启动 2 秒锁定窗口。preview
void GreenTracker_Pause(void)立即制动并进入 PAUSED。preview
uint8_t GreenTracker_Resume(void)从 PAUSED 恢复到前一运行态。preview
void GreenTracker_Stop(void)停止追踪输出并回到 IDLE。preview
GreenTracker_State_t GreenTracker_GetState(void)返回当前 typed state。preview
const char *GreenTracker_GetStateName(void)返回状态名，供 STATUS 和日志使用。preview
void GreenTracker_FormatStatus(char *buf, size_t len, const char *prefix)输出紧凑调试状态。preview
uint8_t GreenTracker_SetParam(const char *name, float value)现场调参，必须做范围检查。preview
